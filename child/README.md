# installation

before starting the image, make sure to run
```sh
python3 setup_gmail
```
or just modify the `msmtprc` config file yourself in order to have email notification



then create a .env file and fill it in accordingly
```sh
NETDATA_HOSTNAME= {YOUR_HOSTNAME}
```

- - -

Also, make sure to edit the `health_alarm_notify.conf` and `stream.conf` according to your needs
